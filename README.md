# Estudio Jurídico - Sistema de Gestión

Sistema web profesional para la gestión integral de estudios de abogados.

## 🚀 Características

- **Gestión de Clientes**: Registro completo con datos de contacto
- **Gestión de Casos**: Seguimiento de casos por cliente
- **Gestión de Documentos**: Almacenamiento y organización de archivos
- **Agenda de Audiencias**: Calendario de eventos y recordatorios
- **Dashboard**: Vista general del estado del estudio
- **Búsqueda rápida**: Encuentra clientes, casos y documentos fácilmente
- **Responsive**: Funciona perfectamente en móvil y escritorio
- **Almacenamiento local**: Todos los datos se guardan de forma segura

## 📱 Uso en Dispositivos Móviles

1. Abre la app en tu navegador
2. Agrega a pantalla de inicio
3. ¡Funciona como una app nativa!

## 🔧 Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage
- Font Awesome Icons

## 📊 Estadísticas

- Totalmente gratuita
- Sin límites de almacenamiento
- 100% privacidad - tus datos quedan en tu dispositivo

## 🛠️ Instalación Local

1. Descarga o clona este repositorio
2. Abre `index.html` en tu navegador
3. ¡Listo para usar!
